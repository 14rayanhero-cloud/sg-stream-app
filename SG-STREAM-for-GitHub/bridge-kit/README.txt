SG STREAM - GAME BRIDGE (Windows)
=================================
1. Double-click Start-Game-Bridge.bat
2. Paste your bridge key when asked (website > Game bridge page > "Your key").
   The site address and key are remembered in bridge-config.json.
3. Put your GAME window in front. Gifts / likes / chat commands now press keys.

Keys in the console:  P = pause / resume   Q = quit
Test mode (presses nothing):  Start-Game-Bridge.bat --dry
Change account/key:           Start-Game-Bridge.bat --reset

The keys are sent to whichever window is in front. Switch the game link OFF on the website for an instant emergency stop.
Do not share bridge-config.json: it contains your key.
