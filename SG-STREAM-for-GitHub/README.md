# SG STREAM

لوحة تحكم وشاشات بث (Overlays) عربية لمن يبث على **TikTok LIVE** و**Twitch**، أو على المنصتين معاً.
تربط حسابك، وتضيف روابط في OBS، وتتفاعل الشاشات مع الهدايا والمتابعين والاشتراكات والشات مباشرة.

> مشروع مستقل غير تابع لـ TikTok أو Twitch. الاتصال بتيك توك يعتمد على مكتبة غير رسمية، فقد يتأثر لو غيّرت المنصة بروتوكولها.

## ما يدعمه تويتش وما لا يدعمه

الاتصال بتويتش **بدون تسجيل دخول** (قراءة فقط، مثل أي مشاهد)، ويشمل:

- ✅ الشات (مع علامة المشترك)
- ✅ الاشتراكات: جديد، وتجديد، وهدايا الاشتراكات (الجماعية تُحسب مرة وحدة)
- ✅ دعم **Bits** (Cheers): يظهر كهدية باسم `Bits`
- ✅ الغارات (Raids)
- ❌ **المتابعون الجدد** و**نقاط القناة (Channel Points)**: تويتش ما يرسلها في الشات. تحتاج تسجيل دخول صاحب القناة (OAuth) وتطبيق مسجّل في Twitch Developers. **غير مبنية حالياً.**

## التشغيل على جهازك (ويندوز)

1. ثبّت [Node.js](https://nodejs.org) (نسخة LTS، 18 أو أحدث).
2. افتح مجلد المشروع في CMD واكتب:
   ```
   npm install
   npm start
   ```
3. افتح `http://localhost:3000` وأنشئ حساباً.

أو اضغط مرتين على `start.bat`.

## النشر على Render (مجاني) مع Upstash

الاستضافة المجانية ما تحفظ ملفات، فنحفظ الحسابات في قاعدة **Upstash Redis** المجانية.

1. **Upstash:** سجّل في upstash.com ← أنشئ قاعدة Redis (الخطة Free) ← انسخ من قسم REST API القيمتين `UPSTASH_REDIS_REST_URL` و`UPSTASH_REDIS_REST_TOKEN`.
2. **GitHub:** أنشئ مستودعاً جديداً وارفع إليه ملفات المشروع (`server.js`, `package.json`, `package-lock.json`, `.npmrc`, `Dockerfile`, `render.yaml`, مجلد `public`).
3. **Render:** سجّل بحساب GitHub ← New ← **Blueprint** ← اختر المستودع ← الصق القيمتين ← Apply.
4. بعد البناء (حوالي 5 دقايق) تحصل رابطاً مثل `https://sg-stream-xxxx.onrender.com`. سجّل فيه أول حساب: **أول حساب مسجّل هو المالك.**

**ملاحظات الخطة المجانية:** ينام الموقع بعد 15 دقيقة بدون زوار ويصحى خلال دقيقة تقريباً. أثناء البث تظل شاشات OBS ترسل طلبات فما ينام. لو تبي تمنع النوم تماماً استخدم uptimerobot.com (مجاني) ليفحص الرابط كل 5 دقايق. عند الإيقاف والتشغيل يعيد الخادم الاتصال ببثوث التيك توك والتويتش اللي كانت شغّالة.

### المتغيرات (Environment Variables)

| المتغير | مطلوب؟ | الوصف |
|---|---|---|
| `PORT` | لا | المنفذ (افتراضي 3000؛ Render يحدده تلقائياً) |
| `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` | على Render: نعم | حفظ الحسابات. بدونهما يحفظ في ملفات `data/` |
| `DATA_DIR` | لا | مجلد الحفظ المحلي |
| `ADMIN_USER` | لا | اسم مستخدم المالك (وإلا أول حساب مسجّل) |
| `REQUIRE_INVITE=1` | لا | التسجيل بكود دعوة (يُحفظ في `data/invite.txt`) |
| `INVITE_CODE` | لا | تحديد كود الدعوة بنفسك |
| `MAX_USERS` / `MAX_CONNECTIONS` | لا | حدود الحسابات (300) والبثوث المتزامنة (25) |
| `AZURE_SPEECH_KEY` / `AZURE_SPEECH_REGION` | لا | استخدام Azure Speech الرسمي بدل واجهة Edge للصوت السحابي |

## روابط OBS

1. من **مكتبة القوالب** اضغط **«🔗 نسخ رابط OBS»** على القالب.
2. في OBS أضف **Browser Source** والصق الرابط، المقاس `1920 × 1080`.
3. بعدها أي تغيير (الشكل، الألوان، النصوص) تسويه من الموقع وينعكس تلقائياً.

للصوت (التنبيهات والقارئ) فعّل في OBS خيار **Control audio via OBS** لمصدر المتصفح.

لو أصدقاؤك يفتحون الروابط من جهاز ثاني، حدّد عنوان موقعك من **الاتصال بالبث ← عنوان الموقع في روابط OBS**.

## الرد الذكي (روبوت الدردشة)

1. افتح **روبوت الدردشة** وخذ مفتاحاً مجانياً: [Groq](https://console.groq.com/keys) أو [Google Gemini](https://aistudio.google.com/apikey).
2. اختر المزوّد، والصق المفتاح، واضغط **«اختبار المفتاح»**.
3. اختر شخصية البوت أو اكتب **تعليمات النظام (System Prompt)** بنفسك.
4. فعّل **«الرد الذكي التلقائي»**.

الرد يظهر في **شاشة الشات** (والموحّد) ويقرأه القارئ الصوتي. **ما يُكتب داخل شات تيك توك أو تويتش نفسه**: هذا يحتاج كوكي جلسة حسابك ومفتاح مدفوع، فاخترنا نبعده عن حسابك.

الحماية: لا يرد على نفس المشاهد قبل انتهاء مهلته (افتراضي 30 ثانية)، ومهلة عامة بين الردود، وحد أقصى بالدقيقة، وطلب واحد في الوقت. القواعد الأمنية (لا سب، لا سياسة ولا دين، لا روابط، تجاهل السبام) تُضاف دائماً فوق تعليماتك. المفتاح يُحفظ مشفّراً (AES-256-GCM) ولا يرجع للمتصفح.

## جسر الألعاب

المتصفح ما يقدر يضغط أزرار داخل الألعاب، فيلزم برنامج صغير على جهازك (ويندوز فقط):

1. من صفحة **ربط الألعاب** حمّل `game-bridge.js` وانسخ الأمر الجاهز (فيه مفتاحك).
2. جرّب أول مرة بدون ضغط حقيقي: `node game-bridge.js https://موقعك مفتاحك --dry`
3. شغّله بدون `--dry` وخلّ نافذة اللعبة هي الأمامية.

القواعد تدعم تيك توك وتويتش (مع فلتر لكل قاعدة): هدية بالاسم، Bits بحد أدنى، اشتراك، غارة، تكبيس (كل N تكبيسة)، وأمر في الشات. القواعد الجاهزة أمثلة، عدّل الأزرار حسب إعدادات لعبتك.

> ⚠ الضغطات تروح لأي نافذة مركّزة. خذ حذرك، وأوقف الربط من الصفحة (خانة «الربط مفعّل») لو احتجت.

## القراءة الصوتية

الصوت يُولَّد في الخادم كملف MP3 ويشتغل داخل OBS كعنصر `<audio>` عادي، وصوت المتصفح هو الاحتياطي لو انقطع الإنترنت.
المحرّك الافتراضي واجهة «القراءة بصوت عالٍ» في Microsoft Edge (عبر `msedge-tts`)، وهي **غير رسمية**. للاستخدام التجاري الأسلم استخدام **Azure Speech** الرسمي بوضع `AZURE_SPEECH_KEY` و`AZURE_SPEECH_REGION`.

## الباقات (للمالك)

الخادم يدعم باقات مجاني / أسبوعي / شهري ويقدر المالك يفعّلها يدوياً (`POST /api/admin/plan`)، وفرضها على الميزات المدفوعة (الصوت السحابي، الرد الذكي بالمساعد، جسر الألعاب) من `POST /api/admin/settings` بالحقل `enforce`. **واجهة الباقات ولوحة المالك ما انبنت بعد**، والدفع الإلكتروني غير موجود. الفرض مطفي افتراضياً فكل الميزات مجانية.

## هيكل المشروع

```

public/
  index.html       لوحة التحكم + ui.js, views2.js, views3.js, views4.js (الصفحات)
  overlay.html     كل شاشات OBS (قالب لكل view)
  shared.js        إعدادات مشتركة، القوالب، الأصوات، أدوات الصوت

```

## الأمان

- كلمات المرور بـ scrypt، والجلسات كوكي موقّع HttpOnly (و`Secure` خلف HTTPS).
- مفاتيح الـ AI مشفّرة، وكود دعوة اختياري، وحدود لمحاولات الدخول ولطلبات الصوت والفحص.
- رابط OBS فيه مفتاح حسابك: لا تنشره. يعطي صلاحية قراءة أحداث بثك فقط، وليس الدخول لحسابك.

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| `Failed to fetch` عند التسجيل | الصفحة مفتوحة بدون خادم: شغّل `start.bat` وافتح `http://localhost:3000` |
| تيك توك: «تأكد أن الحساب في بث مباشر» | لازم تكون في بث الآن. بعض الاستضافات قد تحظرها تيك توك، جرّب من جهازك |
| العدّاد أو القالب واقف في OBS | في OBS: Refresh cache of current page |
| الصوت ما يشتغل في OBS | فعّل «Control audio via OBS»، أو افتح القارئ في تبويب من صفحة القراءة الصوتية |
| الرد الذكي ما يرد | افتح صفحة البوت: تحت شريط الحالة يظهر آخر خطأ (مفتاح خاطئ، حد الاستخدام…) |

## القيود المعروفة

- متابعو تويتش ونقاط القناة غير مدعومة (تحتاج OAuth).
- الرد الذكي لا يكتب داخل شات المنصة نفسها.
- جسر الألعاب لويندوز فقط، وبعض الألعاب المحمية بمضاد غش قد تتجاهل الضغطات المحاكاة.
- حالة البث على تويتش (مباشر/لا) وعدد المشاهدين غير متاحة بدون تطبيق مسجّل.

## 🎮 برنامج ربط الألعاب الجاهز (ويندوز)
من صفحة «ربط الألعاب» اضغط **📥 تحميل برنامج ربط الألعاب الجاهز (Windows)** ← فك الضغط ← دبل كليك على `Start-Game-Bridge.bat` ← الصق مفتاحك (يظهر في نفس الصفحة). إذا ما عندك Node.js يحمّل نسخة خاصة تلقائياً (مع فحص SHA-256). الموقع والمفتاح يُحفظان في `bridge-config.json`. أثناء التشغيل: `P` إيقاف مؤقت، `Q` خروج. للتجربة بدون ضغط فعلي: `Start-Game-Bridge.bat --dry`.

## 👑 باقات PRO ولوحة المالك
أول حساب يسجّل هو المالك (أو `ADMIN_USER`). من «لوحة المالك» تحدد الأسعار ورابط التواصل وتفعّل/تطفئ القيود، وتفعّل باقة أسبوعية/شهرية لأي مستخدم يدوياً. القيود مطفأة افتراضياً (كل شيء مجاني). لا يوجد دفع تلقائي.

## 💾 حفظ الحسابات
الحسابات تُحفظ في `data/users.json` (كتابة آمنة + نسخة `.bak` تُستعاد تلقائياً لو تلف الملف). على Render المجاني القرص مؤقت، فاستخدم Upstash Redis (`UPSTASH_REDIS_REST_URL/TOKEN`) وإلا تضيع الحسابات عند كل إعادة تشغيل. لا تحذف مجلد `data` أبداً.

## 🟣 متابعو Twitch ونقاط القناة (اختياري)
يحتاج تطبيق Twitch خاص بك (مجاني): سجّل تطبيقاً في https://dev.twitch.tv/console ← رابط العودة (OAuth Redirect) = `https://رابط-موقعك/auth/twitch/callback` ← انسخ Client ID و Client Secret وضعهما في متغيرات البيئة `TWITCH_CLIENT_ID` و`TWITCH_CLIENT_SECRET` (على Render: Environment). بعدها كل مستخدم يضغط «ربط حساب تويتش» من نافذة الاتصال، فتظهر المتابعات الجديدة كتنبيه، وجوائز نقاط القناة كـ«هدية» باسم الجائزة وسعرها (تعمل مع التنبيهات وعجلة الحظ وجسر الألعاب). التوكنات تُخزَّن مشفّرة.

## 🌐 اللغة / Language
زر **English / العربية** أعلى لوحة التحكم وفي شاشة الدخول يبدّل الواجهة بين العربية والإنجليزية (يُحفظ اختيارك). الترجمة في `public/lang-en.js` (قاموس عربي ← إنجليزي) والمحرّك في `public/i18n.js`: أي نص جديد تضيفه بالعربية وتحتاج ترجمته أضفه للقاموس. شاشات OBS نفسها تبقى كما هي.
Use the **English / العربية** button in the header or on the login page to switch the dashboard language (remembered). Translations live in `public/lang-en.js`; the engine is `public/i18n.js`. OBS overlays are not affected.


## 🟩 Kick
كيك أغلق الاتصال المجاني بالشات، فالربط الآن عبر واجهة كيك الرسمية: سجّل تطبيقاً في https://dev.kick.com ، رابط العودة `https://رابط-موقعك/auth/kick/callback` ورابط الـ Webhook `https://رابط-موقعك/kick/webhook` (لازم https عام)، ثم ضع `KICK_CLIENT_ID` و`KICK_CLIENT_SECRET` في متغيرات البيئة. كل مستخدم يضغط «ربط حساب كيك» من نافذة الاتصال، وتصل الأحداث (شات، اشتراكات، هدايا Kicks، متابعون، جوائز النقاط) موقّعة ويتم التحقق من توقيعها.
Kick closed its anonymous chat socket; the integration uses the official API (OAuth + signed webhooks). Register an app at https://dev.kick.com, set the env vars above, and users link their channel from the connection window.
